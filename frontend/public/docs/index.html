Business Context

GlideGate is an agentic, multi-product client onboarding platform for financial services. It automates the intake, KYC/AML compliance verification, document collection, product suitability assessment, and account provisioning for multiple products — in parallel — while keeping humans in the loop for regulated decisions.

The platform is being generalized into the CADF (Client Agentic Development Framework) — a domain-configurable framework where new onboarding domains (Retail/Deposit, Loans, Mortgage, Wealth) can be configured through an admin portal without engineering changes or redeployment.

Products supported

Wealth Management

Equity funds, bonds, savings accounts. KYC + suitability assessment + Sales Manager approval for institutional products.

Retail / Deposit Planned Phase 11

Current + savings accounts. Instant-account product option. Configured entirely through the admin portal.

Loans Roadmap

Consumer + SME loans. Credit bureau pull + affordability + adverse-action records (ECOA).

Mortgage Roadmap

Home + commercial mortgages. Appraisal + title verification + TRID disclosure timing.

SALES_REVIEW applies only to institutional products (equity funds, bonds). Retail products skip directly from REVIEW → KYC. PARALLEL_PRODUCTS runs one Temporal child workflow per selected product concurrently — the first to meet its activation criteria goes live independently.

First-to-complete go-live ✅ Phase 4.6

When a client selects multiple products, each runs in parallel. The first product to satisfy all its activation criteria — KYC passed, fraud cleared, suitability assessed — is provisioned immediately with an account number. Other products continue in background. The advisor panel shows per-product activation badges (ACTIVATED / DECLINED / PENDING) and a "First Live" highlight on the first product to activate.

Document collect-once pattern Phase 4.5

Shared-core documents (Government ID, proof of address, W-9) are collected once and reused across all products that require them. A client never uploads the same document twice. Product-specific documents (investment mandate, loan purpose statement) are collected per-product.

CADF uses a multi-agent system where specialized agents handle distinct parts of the onboarding process. After Phase 0.5, each agent is a LangGraph StateGraph running as Temporal Activities within a durable OnboardingWorkflow.
